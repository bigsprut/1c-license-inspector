# Аудит дизайна и UI «Инспектора лицензий 1С»

Дата: 28.11.2026 · версия на входе: 1.5.32 · версия после правок: **1.5.33**

## Что проверялось и по каким критериям

| Область | Критерий |
|---|---|
| WinForms-практики | фиксированная вёрстка без автмасштаба, шрифты в пикселях, страницы по требованию, никаких свойств, создающих handle до показа окна (правило проекта, иначе падение на Server 2003/2008) |
| Windows UX Guidelines | предсказуемая навигация, доступность действий с клавиатуры, состояния (обычное/наведение/фокус/недоступно), отсутствие «мёртвых» элементов |
| WCAG 2.1 AA | контраст текста ≥ 4,5:1, элементы управления доступны с клавиатуры, у элементов есть доступные имена |
| Типографика и сетка | единая шкала шрифтов, отступы, отсутствие обрезанных подписей и «простыней» текста |
| Данные в UI | пустые состояния, отсутствие чужих/мусорных данных, скрытие неприменимых столбцов |

Проверка: снимки всех шести страниц при 1220×820 (`/shot /page:0..5`), разбор кода
(`src/Ui/*`), расчёт контраста по WCAG, `/navtest` (создание всех страниц).

## Осталось осознанно (не делали)

- **Масштабирование под 125–150 %.** Вёрстка умышленно фиксированная (96 DPI, шрифты в пикселях):
  автмасштаб WinForms ломал страницы на Server 2003/2008. Переход на per-monitor DPI — отдельная
  задача с переделкой всех отступов.
- **Полная клавиатурная навигация** (стрелки по боковому меню, горячие клавиши страниц) — сейчас
  Tab + Space/Enter и F5. Следующий шаг.
- **Цветовые бейджи уровней в журнале** — сделан фильтр и сортировка, окраска строк осталась
  необязательной.
- **Подсказки у обрезанных ячеек** — обрезка с многоточием остаётся, но значимые поля
  (номера, базы, лицензии) теперь имеют достаточную ширину или расшифровку в карточке.
- **Локализация названий типов ключей Sentinel** — приходят из Admin API как есть.

## Как проверялось после правок

1. Снимки страниц 0–5: пустые области исчезли, все элементы в пределах окна.
2. `/navtest`: `form: shown`, `page 0..5 ok`, `nav 0..5 done`, `main: form closed` — без падений.
3. Контраст пересчитан по формуле WCAG (см. таблицу выше), значения ≥ 4,5:1.
4. Двойной клик/Enter по кнопкам и Esc в диалогах — проверено на месте.
