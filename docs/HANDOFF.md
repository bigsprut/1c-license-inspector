## Что работает

1. **8.3** — через `rac` (ras `localhost:1545`): сеансы, процессы, лицензии.
   - Основной запрос сеансов — **без** `--licenses`; на живом кластере ответ **с** ключом
     содержит только лицензионную часть (нет базы и времени начала). Лицензии добираются
     отдельным запросом и переносятся по UUID сеанса.
   - `rac cluster admin list` — список администраторов кластера (способы входа `pwd`/`os`/`publickey`).
   - Версии `rac`/`ras`/кластера должны совпадать: приложение берёт `rac` от версии работающего
     `ras.exe`/агента, затем перебирает остальные платформы.
2. **8.2** — через консоль MMC (MMC 2.0, `1CV8 Servers (x86-64).msc`), узлы «Рабочие процессы»
   и «Сеансы». Строка лицензии в консоли: `Сервер, <PIN> <занято> <всего>`.
   - Файлы `*.lic` в 8.2 **зашифрованы** — PIN и места снаружи не читаются.
   - Сводка считается `CollectLicenses.Build82`: клиентские — по строкам **сеансов**,
     серверная — по строкам **рабочих процессов** и помечается «занята работающим сервером»
     (раньше 4 rphost с одной лицензией давали «занято 4 из 1»).
3. **Первая страница «Лицензии и сеансы»** (`src/Ui/Pages/LicenseUsagePage.cs`) — открывается
   при запуске. Две таблицы: «Лицензии» (рег. номер · тип · мест · занято · свободно · источник)
   и «Использование лицензий сеансами» (рег. номер · пользователь · компьютер · база · № ·
   начало · активность · приложение · состояние · лицензия · мест · сеансов). Кнопка
   «Копировать таблицы» и Ctrl+C копируют обе таблицы в буфер через табуляцию.
4. Логика лицензий: «Мест» — ёмкость, «Сеансов/Занято» — сколько **сеансов** держат лицензию;
   у спящих сеансов (`hibernate: yes`) лицензия освобождена — показывается «не выдана (спит)».
5. Выгрузка на диск через RDP-редирект (`src/AutoDrop.cs`): `drop\report-*.html`, `digest-*.txt`,
   `latest-digest.txt`, `latest.log`, `latest-82-*.txt`. **Агент читает оттуда сам.**
6. CLI: `/digest:<file>`, `/report:<file>`, `/csv:<file>`, `/rac:<path>`, `/clusteruser:`,
   `/clusterpwd:`, `/racprobe[:<file>]`, `/selftest`, `/navtest`, `/shot:`, `/demo82`, `/silent`,
   `/noerrorbox`, `/page:`, `/usagetab:`, `/shotsize:`.
7. **Страницы (7)**: 0 Лицензии и сеансы · 1 Обзор · 2 Платформы · 3 Аппаратные ключи ·
   4 Программные лицензии · 5 Использование · 6 Журнал.

## Удалённый прогон на серверах (важное, сделано 28.11.2026)

Снаружи открыты только RDP-порты (55200 и 55210) — WinRM/WMI недоступны. Обмен через
перенаправленную папку RDP: `\\tsclient\D\work\Learn\DSHarness\1CCommon`.

- **Обработчик** — `build\Worker.exe` (исходник `tools\Worker.cs`, C#, без PowerShell).
  Почему C#: на Server 2003 стоит **PowerShell 1.0**, где нет `try/catch` и `-ExecutionPolicy`,
  и PS-версия обработчика там не запускалась (подтверждено отчётом `drop\diag-<host>-s200.txt`).
- Запуск на сервере (в RDP-сеансе, двойной щелчок): `Обработчик-ALL.cmd` (2016, очередь `all`)
  или `Обработчик-S200.cmd` (2003, очередь `s200`). Окно закрыть = доступ выключен,
  в системе ничего не остаётся. `Запуск-с-диагностикой.cmd` пишет в `drop\diag-<host>-<имя>.txt`
  версию .NET, наличие exe и весь вывод обработчика.
- Задание: `.\tools\queue-send.ps1 -Command digest -Server all -TimeoutSec 300`
  (или `-Server s200`). Команды: `noop`, `version`, `digest`, `racprobe`, `selftest`,
  `navtest`, `netstat`, `services`, `copy-log`, `start-ras`.
- Признак жизни: `drop\worker-all.txt` / `drop\worker-s200.txt`; лог — `drop\worker-<имя>.log`.
- Обработчик берёт **самый свежий** exe из `build\` или `dist\` (бывает, что `build\` занят
  открытым окном), копирует его в `%TEMP%\1c-inspector-worker\1cli.exe` и запускает локально
  (с UNC на 2003 приложение грузиться не хочет). Отчёт пишется в локальный файл, затем
  копируется в `drop` — запись в UNC из приложения иногда висит.

(`digest` → файл в `drop`). На <host> в отчёте: 3 зашифрованных `.lic`, сводка

## Грабли (коротко, проверено)

- Кириллицу в `.cs` менять только через edit/write; PowerShell `-replace` не находит.
- `.NET 4.0`: нет `Marshal.StructureToPtr<T>`, нет `StandardOutputEncoding`.
- `rc=0` + пустой stdout у `rac` — это успех, не сбой; нельзя затирать ошибкой следующей попытки.
- **`rac --licenses`** меняет ответ: без ключа — полные сеансы, с ключом — только лицензии.
- Скрипт `Start-Process -Wait` в среде DSH подвисал; GUI-exe из PowerShell ждать через
  `cmd /c "…exe /args"`.
- **`.cmd` только CRLF + ASCII**; `%~dp0` оканчивается на `\` — срезать перед подстановкой в аргумент.
- DataGridView: строки таблиц — **свойства, не поля** (иначе грид пустой); `Rows.Count`, а не
  `rows.Count`; скрывать столбец под `CurrentCell` нельзя (исключение «нельзя сделать невидимой»).
- `Theme.Muted` затемнён до `#5F6E7E` (контраст WCAG); кнопки-ссылки — `AccentText`.
- Проверять версию запущенного файла: в `build\` и `dist\` копии обязаны совпадать (сборка
  сверяет SHA-256) — уже случалось, что запускалась старая версия.
- Не `present`-ить `build\1C-License-Inspector.exe` перед пересборкой: карточка файла держит
  его и сборка не может перезаписать.
- Секрет-скан `publish.ps1` не смотрит в `drop/`, `queue/`, `build/`, `dist/`; в коде/доках
  не должно быть реальных PIN, имён серверов и пользователей (однажды уже утекли).
