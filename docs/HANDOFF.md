## Что работает

### Полное приложение (7 страниц)

0. **Лицензии и сеансы** — открывается при запуске (`src\Ui\Pages\LicenseUsagePage.cs`):
   - «Лицензии»: рег. номер · тип · мест · занято · свободно · **срок действия** ·
     **выдана сервером** · источник · файл;
   - «Использование лицензий сеансами»: рег. номер · пользователь · компьютер · IP ·
     инф. база · начало · **активность** · приложение · состояние · мест / занято.
   «Копировать таблицы»/Ctrl+C — обе таблицы с табуляцией.
1. Обзор · 2. Платформы 1С · 3. Аппаратные ключи · 4. Программные лицензии ·
   5. Использование (вкладки: процессы, службы, порты, **сеансы и лицензии**,
   **нагрузка**) · 6. Журнал.

### Нагрузка сеансов (1.7.0)

Пятая страница, последняя вкладка — `src\Ui\Pages\UsagePage.cs` (`BuildLoadPanel` + `BindLoad`).

- Столбцы: Инф. база · Пользователь · Компьютер · Приложение · Состояние ·
  **Длительность** · **Вызовов** · **мс/вызов** · **CPU** · **БД**; сверху самый долгий сеанс,
  внизу итог по всем («Сеансов: N · вызовов … · продолжительность … · CPU … · данные СУБД …»),
  и отдельной строкой, что поля rac, а не наши вычисления.
- Источник — поля `rac session list`: `duration-all`, `calls-all`, `cpu-time-total`,
  `dbms-bytes-all` (+ `duration-all-dbms`, `duration-all-service`, `bytes-all` для карточки).
  **Единицы:** `duration-*` и `cpu-time-*` — **миллисекунды**, `bytes-*` — байты.
  Проверено на живом 8.3.27: 886 вызовов → `duration-all` 128964 (145 мс на вызов);
  если бы это были секунды, сеанс «работал» бы 35 часов при возрасте 18 часов.
- В `Model.SessionEntry` счётчики — `long`, **-1 = поля нет** (8.2 и старый rac),
  0 — честный ноль. Признак `HasLoad` — есть ли хоть один счётчик.
- Если счётчиков нет ни у кого, вкладка пишет, что кластер их не отдал (8.2), а не рисует нули.
- Те же цифры — в карточке сеанса (`src\Ui\SessionCard.cs`, общая с кратким приложением):
  «Нагрузка / Из вызовов (в СУБД, в коде 1С) / Данные (СУБД, клиенту)» сразу после «Состояния»,
  **до** лицензионных строк. Высота карточки: полное приложение — 176 px (`detailsHost`,
  с линией-разделителем), краткое — 186 px; при прежних 96/132 блок нагрузки уходил под прокрутку.
- Дайджест (`Report.BuildDigest`) дописывает к строке сеанса `нагрузка=…` — так «кто греет
  сервер» видно с боевого сервера через очередь, без окна.
- Заглушка (`tools\racstub.cs`) отдаёт счётчики во всех режимах; в `many` восьмой сеанс
  приходит **без** них — проверка итога «без счётчиков: 1».

### Данные и правила

- **8.3** — через `rac` (ras `localhost:1545`): сеансы, процессы, лицензии. Основной запрос сеансов —
  **без** `--licenses` (на живом кластере ответ с ключом содержит только лицензионную часть);
  лицензии добираются отдельным запросом и переносятся по UUID сеанса. Версии `rac`/`ras`/кластера
  должны совпадать: приложение берёт `rac` от работающего `ras`/агента, затем перебирает платформы.
- **8.2** — консоль MMC (MMC 2.0), узлы «Рабочие процессы» и «Сеансы». Строка лицензии в консоли:
  `Сервер, <PIN> <занято> <всего>`. Файлы `*.lic` в 8.2 **зашифрованы** (см. `LICENSES.md`).
  Сводка — `CollectLicenses.Build82`: клиентские по строкам сеансов, серверная по строкам процессов
  и помечается «занята работающим сервером».
- **Срок действия** — из `*.lic`; «не ограничен» → «бессрочно». У 8.2 файлы зашифрованы → прочерк.
- **«Выдана сервером»** — `issued-by-server` из **сеансов** (не из файла). У 8.2 такого поля нет
  вообще → всегда «—» и пояснение в подсказке. Пустое значение никогда не превращается в «нет».
- **Рег. номер в файле длиннее серии на контрольный знак** (`123456789O0` против `123456789`) —
  сверка только через `CollectLicenses.PinMatches`.
- **Спящие сеансы**: `host` пуст, `connection`/`process` — нулевые UUID, в `connection list` только
  серверные соединения. Единственная примета — `client-ip` (столбец «IP»); для приватных адресов
  пробуется обратный DNS с потолком 900 мс, публичный NAT не резолвим.
- **Активность** (с 1.6.1) — `last-active-at` из rac во всех таблицах и в карточке сеанса.
- **Приложения** — по-человечески (`Fmt.AppName`): `1CV8C` → «Тонкий клиент», `Designer` →
  «Конфигуратор», `WebClient` → «Веб-клиент», `BackgroundJob` → «Фон. задание».
- **Страницы растягиваются с окном** (`PageBase.MarkGrowRow`): сеансы на первой странице,
  область вкладок «Использования», таблица журнала. Грабля: `SetRowHeight` обязан обновлять
  базовую сумму `_totalHeight`, иначе «растущая» строка считает свободное место неверно.
- Выгрузка на диск через RDP-редирект (`src\AutoDrop.cs`): `drop\report-*.html`, `digest-*.txt`,
  `latest-*.txt`. **Агент читает оттуда сам.**
- CLI полного приложения: `/digest:`, `/report:`, `/csv:`, `/rac:`, `/clusteruser:`, `/clusterpwd:`,
  `/racprobe[:]`, `/selftest`, `/navtest`, `/shot:`, `/demo82`, `/silent`, `/noerrorbox`, `/page:`,
  `/usagetab:`, `/shotsize:`, `/about` (+ `/shot:`).

## Грабли (коротко, проверено)

- **`/shot` с `/silent` ничего не снимает** — ветка `/silent` выходит раньше скриншота.
- **Два exe из одних исходников**: csc требует `/main:` (иначе CS0017).
- **`PageBase.Col(g, …)` сам добавляет столбец** — `Columns.Add(Col(…))` даёт
  `InvalidOperationException: столбец уже принадлежит DataGridView`.
- **Сборка терпит занятые файлы**: занятый `build\1C-License-Inspector.exe` → собирает в
  `1C-License-Inspector.new.exe` и обновляет `dist\`; занятый `build\Worker.exe` → оставляет
  новый бинарник в **`build\Worker-ready.exe`** (подменить после закрытия окна обработчика).
- **Иконки в кэше Windows**: 2016/10 кэшируют иконку по пути. Обработчик с 1.6.2 называет копию
  с версией (`1cli-1_6_3.exe`), старые удаляет. Разово: `ie4uinit.exe -show` или перезапуск
  проводника; у закреплённого ярлыка — открепить/закрепить.
- **`rac`**: `rc=0` + пустой stdout — это успех; `--licenses` меняет ответ (без ключа — полные сеансы).
- **Единицы `rac`** (1.7.0): `duration-*` и `cpu-time-*` — **миллисекунды**, `bytes-*` — байты.
  В справке `rac` единицы не написаны, поэтому проверять на своих данных: у сеанса с 886 вызовами
  `duration-all` = 128964 → 145 мс на вызов (а не «35 часов работы» при возрасте сеанса 18 часов).
- **Карточка сеанса** — в панели `detailsHost` (176 px, линия-разделитель сверху), текстбокс внутри
  с `Dock=Fill`. Без панели первая строка карточки прилипает к последней строке таблицы и читается
  как её продолжение.
- **`Fmt.Bytes`** с 1.7.0 считает в текущей культуре — «133,9 МБ», как и время («2,5 с»).
  Раньше в одной таблице соседствовали «133.9 МБ» и «2,5 с».
- **DataGridView**: строки — свойства, не поля; `Rows.Count`, а не `rows.Count`; нельзя скрыть
  столбец под `CurrentCell`.
- **`.NET 4.0` и Server 2003**: никаких `AssemblyMetadata`, `StandardOutputEncoding`,
  `Marshal.StructureToPtr<T>`; шрифты в пикселях, `AutoScaleMode.None`.
- Кириллицу в `.cs` менять только через `edit`/`write` (PowerShell `-replace` не находит).
- Не перезаписывать файлы целиком вместо точечной правки — так уже портились `UsagePage.cs`
  и `build.yml` (восстанавливать `git checkout HEAD -- <файл>`).
- Секрет-скан `publish.ps1` ловит `\b[0-9]{10}\b` (PIN) и IP; реальные данные — только в `drop\`
  (в `.gitignore`), в коде и документации — заглушки.
